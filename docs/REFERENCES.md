# References and attribution

References inspected during implementation, 30 September 2026:

- [James Sullivan's multi-agent-social-deduction](https://github.com/james-sullivan/multi-agent-social-deduction): Python game orchestration, player tools, shared Anthropic integration, event tracking and configuration. The original source remains under `multi-agent-social-deduction/`. The new `clocktower` package does not import it. MIT copyright (c) 2025 James Sullivan is retained in `LICENSE.txt`.
- [Linked visualizer](https://james-sullivan.github.io/botc-visualizer/) and [source repository](https://github.com/james-sullivan/botc-visualizer): React/TypeScript log viewer with event timeline, player status and statically registered JSONL files. The rewrite uses the timeline and seating concepts with dynamically discovered runs, local configuration, launch/stop, persona management, perspective filtering and playback. No visualizer code or artwork was copied.
- [Official Trouble Brewing script](https://wiki.bloodontheclocktower.com/Trouble_Brewing), [setup](https://wiki.bloodontheclocktower.com/Setup), [rules explanation](https://wiki.bloodontheclocktower.com/Rules_Explanation), [states](https://wiki.bloodontheclocktower.com/States) and individual official character pages linked from the script. Focused interaction references include [Imp](https://wiki.bloodontheclocktower.com/Imp), [Scarlet Woman](https://wiki.bloodontheclocktower.com/Scarlet_Woman), [Virgin](https://wiki.bloodontheclocktower.com/Virgin), [Butler](https://wiki.bloodontheclocktower.com/Butler), [Washerwoman](https://wiki.bloodontheclocktower.com/Washerwoman), [Poisoner](https://wiki.bloodontheclocktower.com/Poisoner), [Monk](https://wiki.bloodontheclocktower.com/Monk), [Fortune Teller](https://wiki.bloodontheclocktower.com/Fortune_Teller) and [Undertaker](https://wiki.bloodontheclocktower.com/Undertaker).
- [CERIT/e-INFRA API documentation](https://docs.cerit.io/en/docs/ai-as-a-service/ai-api): API-key creation, Bearer authentication, `https://llm.ai.e-infra.cz/v1/`, model discovery, Chat Completions and documented compatibility limits. [Model availability and access](https://docs.cerit.io/en/docs/ai-as-a-service/chat-ai) explains aliases and changing model availability.
- [OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat): messages, output token limits and usage fields.
- [Anthropic API overview](https://platform.claude.com/docs/en/api/overview): Messages endpoint, API-version header and API-key authentication.
